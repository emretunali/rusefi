You own `firmware/config/boards/spark-ems/amiral/`.

## What you must know before editing

- Amiral is **STM32F7 only**, seeded from `hellen/alphax-8chan` (F7 variant) on a
  Hellen Mega-Module 176. Pin symbols come from `config/boards/hellen_mm176_meta.h`
  (the `MM176_*` namespace) and `hellen_meta.h` (`H176_*`).
- The connector YAMLs under `connectors/` are the **source of truth** for pin names.
  `connectors/generated_*` are build outputs regenerated by `firmware/rusefi_config.mk`
  from those YAMLs - never hand-edit them, edit the YAML and rebuild.
- `board_config.txt` fields are appended to `engine_configuration_s` for this board
  only. Adding or reordering them changes the tune layout: read
  `docs/calibration-compatibility.md` before touching existing fields.
- Comments in `prepend*.txt` and other config `.txt` files use `!` or `//`.
  A `;` or a bare `#` line makes the config generator throw
  `IllegalStateException: Unexpected line while prepending`.
- `set8chanDefaultETBPins` in `board_configuration.cpp` is **not** ours to rename:
  `firmware/config/engines/gm_sbc.cpp` forward-declares and calls it across
  translation units.
- Board override hooks (`custom_board_DefaultConfiguration`, `custom_board_ConfigOverrides`,
  `custom_board_InitHardware`, `custom_board_fix_configuration`) each run at a
  different point in startup - see `docs/board-configuration-override-hooks.md`.
  `custom_board_validateConfig` must never mutate config.

## Validation - always, before reporting done

```bash
./gradlew :config_definition:shadowJar          # once per container (needs JDK 11)
firmware/gen_config_board.sh config/boards/spark-ems/amiral amiral
```
A successful run ends with `Happy amiral!`. A board change that has not been through
config generation is not finished. If an ARM toolchain is available, also run
`firmware/config/boards/spark-ems/amiral/compile_amiral.sh` - if it is not, say so
rather than implying the firmware built.

Never commit generated output (`firmware/controllers/generated/*`,
`firmware/tunerstudio/generated/*`, `firmware/controllers/lua/generated/*`). The one
exception is `connectors/generated_*`, which upstream tracks in git for every board.

Keep `firmware/config/boards/spark-ems/amiral/readme.md` - especially its
"deliberate deviations" table - accurate as you change things.
